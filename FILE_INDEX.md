## 💡 HELPFUL TIPS

**Adding New Pages:**
1. Create directory in `app/[section]/[page-name]/`
2. Copy template `page.tsx` from similar page type
3. Update metadata (title, description)
4. Modify content sections
5. Test locally with `npm run dev`

**Updating Styles:**
- Global changes → `app/globals.css`
- Component-specific → inline Tailwind classes
- Brand colors → `tailwind.config.js`

**Testing:**
- Local: `npm run dev` → http://localhost:3000
- Build: `npm run build` → Check for errors
- Staging: Deploy to Manus/Lovable
